# Engine Wrapper
## Задание
Проект реализует систему инкапсуляции методов класса произвольной сигнатуры с возможностью регистрации и выполнения команд через единый интерфейс
## Требования
- C++17 или выше
- CMake 3.10 или выше
- Компилятор с поддержкой стандартной библиотеки C++17
## Струкутра проекта
```
Engine Wrapper/
├── Engine.h          # Класс Engine для управления командами
├── ICommand.h        # Интерфейс ICommand (абстрактный базовый класс)
├── Wrapper.h         # Шаблонный класс Wrapper для обертки методов
├── Subject.h         # Пример класса с методами для тестирования
├── Tests.h           # Заголовочный файл для тестирования
├── Tests.cpp         # Реализация всех тестов
└── main.cpp          # Точка входа в программу
```

## Архитектура
### ICommand (Интерфейс команды)
- Абстрактный базовый класс для всех команд
- Определяет интерфейс выполнения команды
- Поддерживает передачу аргументов в виде словаря
### Wrapper (Обертка метода)
Шаблонный класс, который:
- Принимает указатель на объект и метод
- Хранит имена аргументов и значения по умолчанию
- Реализует интерфейс ICommand
- Поддерживает методы с любым количеством аргументов
### Engine (Движок команд)
- Хранит зарегистрированные команды в словаре
- Предоставляет методы для регистрации и выполнения команд
- Автоматически управляет памятью через `std::unique_ptr`
### Subject (Тестовый класс)
- Пример класса с методами для демонстрации
- Содержит методы с разным количеством аргументов
## Особенности реализации
### Безопасность памяти
- Использование `std::unique_ptr` для автоматического управления памятью
- Отсутствие утечек памяти благодаря RAII
### Обработка ошибок
- Проверка наличия всех обязательных аргументов
- Валидация количества аргументов
- Обработка неизвестных команд
### Гибкость
- Поддержка методов без аргументов
- Возможность перезаписи команд
- Независимость от конкретных классов
## Пример использования
```C++
Subject obj;
Engine engine;

engine.register_command(
    std::unique_ptr<ICommand>(new Wrapper<Subject, int, int, int>(
        &obj, &Subject::f3,
        std::map<std::string, int>{{"a", 0}, {"b", 0}})),
    "add");

int result = engine.execute("add", std::map<std::string, int>{{"a", 5}, {"b", 3}});
// result = 8
```
